# Product Vision

## Purpose

Define the high-level product direction for the SDD template repository.

## Scope

This document captures product intent, not implementation detail.

## Inputs

- Teams starting new repositories from this template
- Product-specific specs added after template adoption
- Baseline SDD workflow expectations from `AGENTS.md`

## Outputs

- A reusable repository foundation for SDD-based coding
- Clear separation between template-owned workflow and product-specific behavior
- Traceable evolution from specs to implementation

## Acceptance Criteria

- The spec is understandable to a new contributor.
- Related implementation links back to this spec when added.
- Template guidance stays product-neutral until a derived repository replaces it.

## Validation

- Reviewed during SDD planning and pull request review.
